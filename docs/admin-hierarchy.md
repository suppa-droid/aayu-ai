# Three-Tier Human-in-the-Loop Admin Hierarchy

## Level 1: Field-level Admin (Anganwadi / NGO Worker)
- Customer facing.
- Registers senior citizens on tablet kiosk.
- Captures & verifies physical documents.
- Builds in-person trust during home visits.

## Level 2: District / Backend Admin (CSC Operator / NGO Coordinator)
- Monitors escalation dashboard for stuck cases.
- Resolves name mismatches, blurry document re-scans, or application rejections.
- Uses AI-generated draft appeals to resolve disputes.

## Level 3: System Admin (Technical Team)
- Maintains the scheme rule database YAML definitions.
- Updates eligibility logic as government policies change.
- Monitors AI pipeline health, RAG accuracy, and agent state transitions.
